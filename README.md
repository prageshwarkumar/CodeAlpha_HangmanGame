# CodeAlpha Hangman Game

A word-guessing game developed in Python as part of the CodeAlpha Python Programming Internship.

## Features

- Graphical user interface built with Tkinter
- Multiple word categories: Fruits, Animals, and Colors
- Random word selection
- Letter validation and duplicate-guess prevention
- Six incorrect attempts allowed
- Win and lose messages
- Restart button
- Dark-themed interface

## Technologies Used

- Python
- Tkinter
- GitHub

## Requirements

- Python 3
- Tkinter (usually included with standard Python installations)

## How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run the following command:

   `python hangman.py`

## Project Purpose

This project demonstrates Python fundamentals, including conditional statements, lists, dictionaries, loops, functions, random selection, and GUI development.
